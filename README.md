# Dream Shop

A full-stack e-commerce web application built with modern web technologies.

## Project Overview

Dream Shop is an e-commerce platform where users can browse products, manage their shopping carts, and explore an admin dashboard for product and category management.

## Technology Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS
- Lucide Icons

### Backend
- Node.js
- Express.js
- TypeScript

### Database
- MongoDB
- Mongoose

### Tools & Services
- Git & GitHub
- Postman
- Cloudinary
- Vercel
- Render
